# CONTROL — frontend prototype

Фронтенд реализован на чистом HTML, CSS и JavaScript ES2020+ с ES Modules. Фреймворки, сборщики и внешние CDN не используются.

## Запуск

Откройте `index.html` через локальный HTTP-сервер. Например, из корня проекта:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Структура

- `index.html` — точка входа.
- `config.js` — пример конфигурации API (в `js/config.js`).
- `css/styles.css` — стили.
- `js/main.js` — логика текущего интерактивного макета.
- `js/i18n.js` — русскоязычные строки.

## Текущее состояние

Это перенесённый интерактивный макет: вход демонстрационный, данные событий тестовые, API не подключён. Экранные разделы и операции, обозначенные в макете как заглушки, требуют реализации по API-контракту проекта.
